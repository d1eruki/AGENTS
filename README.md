# Репозиторий инструкций и скиллов для агентов

Хранилище глобальных инструкций и специализированных скиллов для ИИ-агентов. Глобальная инструкция задаёт обязательный порядок работы и маршрутизацию, а скиллы содержат подробные процедуры для конкретных задач.

## Назначение

Весь репозиторий подключается как `~/.codex/agent-guidance`, а [`instructions/global.md`](./instructions/global.md) — как `~/.codex/AGENTS.md`. Глобальная инструкция действует во всех проектах, а тематические маршрутизаторы загружают только нужные скиллы, чтобы подробные инструкции не занимали контекст каждой задачи.

Папки скиллов подключаются в `~/.agents/skills` симлинками. Синхронизатор также поддерживает глобальные ссылки и удаляет прежние ссылки этого репозитория из `~/.codex/skills`. После клонирования репозитория или добавления, удаления, переименования либо перемещения скилла необходимо выполнить:

```sh
./scripts/sync-skills.sh
./scripts/sync-skills.sh --check
```

## Инструкции

Инструкции задают общие правила и помогают выбрать нужный процесс. Подробные процедуры остаются в скиллах и читаются только для подходящих задач.

| Инструкция | Назначение |
| --- | --- |
| [`instructions/global.md`](./instructions/global.md) | Глобальные правила: план и одобрение перед правками, маршрутизация, синхронизация скиллов, язык, документация и проверки. Подключается как `~/.codex/AGENTS.md`. |
| [`instructions/frontend.md`](./instructions/frontend.md) | Выбирает скиллы для архитектуры фронтенда, Vue, Tailwind CSS, зависимостей и проверки изменений. |
| [`instructions/figma.md`](./instructions/figma.md) | Выбирает скиллы для дизайн-систем, структуры страниц и вайрфреймов в Figma. |

## Формат скилла

Рекомендации:

- `SKILL.md` содержит вводные метаданные с `name` и `description`, затем полную инструкцию для агента.
- `description` должен чётко описывать, когда скилл нужно использовать и когда не нужно.
- `agents/` хранит метаданные для конкретной среды выполнения, если они нужны.
- `references/` хранит справочные материалы, которые агент должен читать только при необходимости.
- Скилл должен быть самодостаточным: агенту должно хватать содержимого каталога, чтобы выполнить задачу.
- Обязательные правила для каждой задачи хранятся в глобальной инструкции и не дублируются в скиллах.
