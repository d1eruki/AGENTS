# Маршрутизатор инструкций по фронтенду

Определи фактический стек проекта и нужный пользователю результат, затем прочитай только подходящие инструкции:

- Сквозная архитектура фронтенда, общее поведение в браузере, токены дизайна, адаптивные системы или многоуровневая диагностика: прочитай [engineering.md](references/engineering.md).
- Компоненты Vue, реактивность, композиционные функции, владение состоянием или жизненный цикл: прочитай [vue.md](references/vue.md).
- Утилиты Tailwind, варианты, токены темы, адаптивные классы или решения о собственном CSS: прочитай [tailwind.md](references/tailwind.md).
- Среда выполнения, зависимости, инструменты, совместимость или модернизация: прочитай [maintenance.md](references/maintenance.md).
- Браузерные 3D-сцены, модели, материалы, преломление, физический масштаб или производительность рендера: прочитай [3d-scenes.md](references/3d-scenes.md).
- Проектирование фронтенд-тестов, визуальная оценка, проверки поведения или стратегия валидации: прочитай [verification.md](references/verification.md).

Читай несколько веток, только если задача независимо требует каждой из них. Обычная сборка страницы сама по себе не требует инструкции `engineering/index.md`.
