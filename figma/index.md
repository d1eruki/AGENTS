# Маршрутизатор инструкций по Figma

Определи нужный пользователю результат в Figma, затем прочитай только подходящую инструкцию:

- Аудит, создание, рефакторинг, документирование или внедрение дизайн-системы в существующем файле Figma: прочитай [design-system.md](references/design-system.md).
- Сборка или адаптация страниц на адаптивной сетке с переменными: прочитай [layout-structure.md](references/layout-structure.md).
- Создание десктопных низкодетализированных вайрфреймов лендинга и связанных страниц: прочитай [wireframes.md](references/wireframes.md).

Если выбранный процесс требует инструмента Figma, перед его вызовом выполни все обязательные условия текущей интеграции Figma. Не создавай новый файл Figma без явной просьбы пользователя.
