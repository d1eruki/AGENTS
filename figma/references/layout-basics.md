# Базовая компоновка в Figma

Используй эти правила при создании или изменении макета Figma, если задача затрагивает структуру элементов. Проектные требования к конкретному экрану и явно заданная композиция имеют приоритет.

- По возможности задавай текстовым слоям ширину и высоту по содержимому (`HUG`). Если текст должен переноситься внутри контейнера, задай ему доступную ширину и высоту по содержимому.
- Собирай связанные элементы в горизонтальные и вертикальные контейнеры Auto Layout; для сложного блока используй вложенные контейнеры вместо независимой ручной расстановки каждого элемента.
- Не навязывай автоматическую компоновку декоративным слоям и элементам, для которых дизайн требует фиксированных размеров или абсолютного положения.
- При продолжении существующего макета сначала проверь его текущую структуру и последние ручные правки пользователя. Не заменяй их более «правильной» схемой без необходимости.

Для адаптивной страницы с переменными и контейнерами дополнительно читай [layout-structure.md](layout-structure.md). Для низкодетализированного вайрфрейма соблюдай его отдельные правила текста и размеров из [wireframes.md](wireframes.md).
