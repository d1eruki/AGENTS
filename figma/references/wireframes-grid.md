# Сетка и колонки вайрфрейма

## Сетка макета

Применяй эту сетку к каждому фрейму страницы шириной 1280 пикселей:

```js
frame.layoutGrids = [
  {
    pattern: "COLUMNS",
    visible: true,
    color: { r: 0.2, g: 0.2, b: 0.2, a: 0.12 },
    alignment: "STRETCH",
    gutterSize: 20,
    offset: 60,
    count: 12,
  },
];
```

По возможности создай стиль сетки `Wireframe / Desktop 12 Columns` и назначь его фреймам. Если в текущем контексте нельзя создать стиль, примени объект сетки напрямую к каждому фрейму.

## Правила создания сетки автоматической компоновки

Для повторяющихся групп карточек используй настоящие сетки Figma Auto Layout, а не визуальные сетки макета.

Не путай:

- `layoutGrids` — визуальная сетка поверх макета;
- `layoutMode = "GRID"` — настоящий контейнер сетки с автоматической компоновкой.

Не используй ранее изменённый контейнер сетки при смене структуры строк или колонок. Создай его заново.

Причина: Figma может сохранить устаревшее состояние строк или дорожек, из-за чего интерфейс покажет удвоенные строки, например `4 x 2` вместо `4 x 1`.

### Правильный порядок

1. Собери существующие узлы карточек.
2. Создай новый фрейм.
3. До добавления карточек установи `layoutMode = "GRID"`.
4. Задай новой сетке `gridColumnCount`, `gridColumnGap` и `gridRowGap`. Если поддерживается, также задай `gridRowCount`.
5. До размещения установи ширину каждой карточки по ширине целевой колонки.
6. Вставь карточки через `appendChildAt`.
7. После размещения снова задай ширину карточек.
8. Удали старый контейнер сетки.
9. Определи размер сетки по фактическим границам дочерних элементов.

Не пытайся исправить сломанную сетку `4 x 4`, меняя её на `4 x 2`.

### Схемы сетки

Используй такие значения по умолчанию:

- 4 карточки: `4 колонки × 1 строка`;
- 8 карточек: `4 колонки × 2 строки`;
- 3 карточки: `3 колонки × 1 строка`;
- 5 компактных карточек: `5 колонок × 1 строка`;
- 6 карточек разной ширины: `4 колонки × 2 строки`; первые 4 карточки занимают по `1` колонке, последние 2 — по `2`.

### Настройка контейнера

```js
grid.layoutMode = "GRID";
grid.gridColumnCount = columns;
try {
  grid.gridRowCount = rows;
} catch (error) {
  // Предпочтительный способ не сработал; используй автоматически рассчитываемые строки Figma.
}
grid.gridColumnGap = 20;
grid.gridRowGap = 20;
grid.primaryAxisSizingMode = "FIXED";
grid.counterAxisSizingMode = "FIXED";
grid.resize(1160, computedHeight);
```

Предпочитай явный `gridRowCount`; автоматически рассчитываемые строки — запасной путь. Если установка `gridRowCount` вызывает ошибку из-за автоматического учёта строк в текущем контексте Figma, не считай это провалом создания и не исправляй старую сломанную сетку её изменением. Оставь новую сетку, явно размести дочерние элементы, определи размер по их границам и проверь ожидаемое число строк по позициям элементов.

### Формула ширины карточки

```js
const cardWidth = (containerWidth - gap * (columns - 1)) / columns;
const spannedWidth = cardWidth * span + gap * (span - 1);
```

Задавай ширину карточки до помещения в сетку и повторно после.

Для дочерних элементов сетки:

- Задавай каждой непосредственной карточке фиксированную ширину до и после размещения в сетке.
- Ограничивай текст внутри карточек величиной `card.width - card.paddingLeft - card.paddingRight`.
- Не запускай общую подгонку размеров, которая расширяет дочерние элементы сетки по ширине внутреннего содержимого.

### Правила занятия колонок

Для сеток с разной шириной элементов:

```js
const spans = [1, 1, 1, 1, 2, 2];
```

Размещение:

```js
grid.appendChildAt(card, rowIndex, columnIndex);
card.gridColumnSpan = span;
card.gridRowSpan = 1;
```

Для сетки переводов `4 x 2`:

```js
[
  { row: 0, col: 0, span: 1 },
  { row: 0, col: 1, span: 1 },
  { row: 0, col: 2, span: 1 },
  { row: 0, col: 3, span: 1 },
  { row: 1, col: 0, span: 2 },
  { row: 1, col: 2, span: 2 },
];
```

### Правило высоты

Не определяй высоту по номинальному числу строк. После размещения дочерних элементов:

```js
const maxBottom = Math.max(...grid.children.map((child) => child.y + child.height));

grid.resize(1160, Math.ceil(maxBottom) + 24);
```

Добавка `+24` предотвращает обрезку из-за дробного размещения в сетке Figma.

### Проверка

- на группах карточек нет визуальной сетки `layoutGrids`, если она явно не запрошена;
- каждый намеченный контейнер сетки имеет `layoutMode === "GRID"`;
- ширина контейнера сетки равна `1160`;
- ни один дочерний элемент сетки не шире своей колонки;
- массивы проверки пусты: `badRows.length === 0`, `tooWideFrames.length === 0`, `textTooWide.length === 0`, `overflow.length === 0`;
- ни один дочерний элемент не выходит за родителя:
  - `child.x + child.width <= parent inner width`
  - `child.y + child.height <= parent inner height`

Карта ожидаемых строк для типичных секций лендинга:

```js
const expectedRowsBySection = {
  "Benefits grid": 1,
  Steps: 1,
  "Use cases grid": 2,
  "Selection parameters": 1,
  "Transfers grid": 2,
  "Premium benefits": 1,
  "Security grid": 2,
  "Audience grid": 2,
  "Blog cards": 1,
};
```
