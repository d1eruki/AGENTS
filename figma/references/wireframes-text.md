# Язык и типографика вайрфрейма

## Единый язык интерфейса

Не смешивай русский и английский случайным образом.

Если работаешь по странице-образцу, определи язык создаваемой страницы по нему. Уточняй язык лишь при противоречии между языком образца и предоставленным текстом или когда пользователь явно просит другой язык.

При создании нового вайрфрейма без образца спроси о языке во время сбора исходных данных.

Правила выбранного языка одинаково относятся к русскому и английскому; ни один язык не считается предпочтительным.

- заголовки секций должны соответствовать выбранному или определённому по образцу языку страницы;
- заголовки карточек тоже, если это не термины продукта;
- подписи целевых действий должны быть на выбранном языке;
- термины продукта вроде `crypto top-up`, `Apple Pay`, `Google Pay`, `Premium`, `KYC` и `OTP` могут оставаться на привычном для продукта языке.

В конце проверь подписи интерфейса на смешение языков.

## Типографика русского текста

По возможности не оставляй короткие слова в конце строк русского интерфейсного текста. Удерживай короткие предлоги, союзы и частицы со следующим словом, если это не ухудшает интервалы или переносы.

Примеры слов, которые стоит удерживать со следующим:

- `в`, `во`, `на`, `с`, `со`, `к`, `ко`, `у`, `о`, `об`, `от`, `до`, `за`, `из`, `по`, `для`, `при`, `и`, `а`, `но`, `не`

Используй неразрывные пробелы, если требование сохранить точный текст пользователя не запрещает типографическую правку:

```js
function preventRussianDanglingWords(text) {
  return text.replace(
    /\b(в|во|на|с|со|к|ко|у|о|об|от|до|за|из|по|для|при|и|а|но|не)\s+/gi,
    "$1\u00A0",
  );
}
```

Не переписывай формулировку ради типографики. Только связывай короткие слова со следующими.

Не исправляй типографику ручными переносами строк. Используй неразрывные пробелы для коротких слов и позволяй ширине контейнера определять переносы.

## Типографика английского текста

По возможности не оставляй короткие слова в конце строк английского интерфейсного текста. Удерживай короткие артикли, предлоги и союзы со следующим словом, если это не ухудшает интервалы или переносы.

Примеры слов, которые стоит удерживать со следующим:

- `a`, `an`, `the`, `of`, `to`, `in`, `on`, `at`, `by`, `for`, `with`, `and`, `or`

Используй неразрывные пробелы, если требование сохранить точный текст пользователя не запрещает типографическую правку:

```js
function preventEnglishDanglingWords(text) {
  return text.replace(/\b(a|an|the|of|to|in|on|at|by|for|with|and|or)\s+/gi, "$1\u00A0");
}
```

Не переписывай формулировку ради типографики. Только связывай короткие слова со следующими.

Не исправляй типографику ручными переносами строк. Используй неразрывные пробелы для коротких слов и позволяй ширине контейнера определять переносы.

## Текст

Создавай текст только из предоставленного содержимого. Высота текста должна подстраиваться под него, а ширина ограничиваться областью содержимого родителя.

## Типографическая иерархия

Назначай размеры текста по смысловой роли, а не произвольно для каждой секции.

Иерархия по умолчанию:

- Главный `H1` обычно самый крупный текст страницы.
- `H2` должен быть меньше `H1`.
- `H3` должен быть меньше `H2`.
- `H4` должен быть меньше `H3`.
- `H5` должен быть меньше `H4`.
- Основной текст абзаца не должен быть меньше `16px`.
- Текст подписи должен иметь размер `12-14px`.

Не позволяй заголовку низшего уровня визуально превосходить заголовок высшего. Например:

- заголовок карточки не должен быть крупнее заголовка секции;
- основной текст не должен быть `12px`, если это не явная подпись или мелкий юридический текст;
- подписи не должны выглядеть как основной текст.

При работе по образцу копируй типографические значения по ролям, сохраняя иерархию: `H1 > H2 > H3 > H4 > H5 > p > caption`. Локальное исключение из образца оставляй, только если на новой странице есть та же смысловая роль.

Проверка:

- собери созданные текстовые узлы по ролям;
- убедись, что размеры заголовков уменьшаются по смысловым уровням;
- убедись, что основной текст абзацев не меньше `16px`;
- убедись, что подписи имеют размер от `12px` до `14px`;
- убедись, что подписи целевых действий, кнопок и навигации считаются подписями интерфейса, а не заголовками.

Весь текст должен помещаться внутри родительского контейнера:

- Не оставляй текстовые узлы с `height = 1`.
- Не задавай фиксированную высоту текста без конкретной причины.
- Не вставляй ручные переносы `\n` в предоставленный текст ради композиции. Сохраняй переносы, уже имеющиеся в исходном тексте пользователя.
- Используй `textAutoResize = "HEIGHT"` для текста, который должен переноситься внутри карточки, секции, строки, ячейки таблицы, строки FAQ или колонки содержимого.
- Используй `textAutoResize = "WIDTH_AND_HEIGHT"` только для коротких подписей с собственной шириной: пунктов навигации, переключателей языка, коротких подписей кнопок и небольших плашек.
- Для заголовков и описаний карточек, вопросов FAQ, строк таблицы, основного текста секций и любого длинного текста рассчитывай перенос по доступной внутренней ширине родителя, а в контейнере с автоматической компоновкой завершай настройкой `textAutoResize = "HEIGHT"` и `layoutSizingHorizontal = "FILL"`.
- Доступная ширина равна `parent.width - parent.paddingLeft - parent.paddingRight`.
- Текст не должен быть шире внутренней области содержимого родителя.

Для длинного или переносящегося текста внутри родителей с автоматической компоновкой используй эту вспомогательную функцию:

```js
function fitTextToParent(textNode) {
  const parent = textNode.parent;
  const innerWidth =
    parent && "width" in parent
      ? parent.width - (parent.paddingLeft || 0) - (parent.paddingRight || 0)
      : textNode.width;

  textNode.textAutoResize = "HEIGHT";
  // Временное изменение размера задаёт ширину переноса; итоговые режимы — FILL/HUG.
  textNode.resize(Math.max(40, innerWidth), Math.max(1, textNode.height));

  if ("layoutSizingHorizontal" in textNode) {
    textNode.layoutSizingHorizontal = "FILL";
  }

  if ("layoutSizingVertical" in textNode) {
    textNode.layoutSizingVertical = "HUG";
  }
}
```

Не оставляй текст содержимого в режиме `layoutSizingHorizontal = "FIXED"` после создания, если это не короткая подпись, бейдж, чип, подпись иконки, пункт навигации, переключатель языка или подпись кнопки.

Только для коротких подписей:

```js
textNode.textAutoResize = "WIDTH_AND_HEIGHT";
if ("layoutSizingVertical" in textNode) textNode.layoutSizingVertical = "HUG";
```

## Правила структуры текстовых узлов

Не помещай каждый текстовый узел в отдельный фрейм. Тексту не нужен собственный фрейм только ради размещения во фрейме; компоновкой обычно должен управлять родительский контейнер с автоматической компоновкой.

Обычно текст должен быть непосредственным потомком соответствующего смыслового контейнера:

- заголовок и текст карточки — непосредственные потомки `Card`;
- заголовок и текст секции — непосредственные потомки `Section heading`;
- текст вопроса FAQ — непосредственный потомок `Accordion row`;
- текст таблицы — непосредственный потомок `Table row`;
- подпись кнопки — непосредственный потомок `Button`.

Создавай дополнительный фрейм-обёртку текста только ради реальной задачи компоновки:

- объединить несколько текстовых узлов в повторно используемый блок;
- разделить левую и правую колонки;
- выровнять текст с иконкой или элементом управления;
- применить общие отступы, фон или обводку;
- создать компонент или слот компонента;
- упростить сопровождение повторяющегося паттерна.

Избегай бессмысленных обёрток вроде:

- `Text wrapper`
- `Title container`
- `Label frame`
- отдельных фреймов для каждого текста.

Плохо:

```text
Card
  Title frame
    Text
  Body frame
    Text
```

Хорошо:

```text
Card
  Icon placeholder
  Card title
  Card body
```

При компоновке опирайся на родительский контейнер с автоматической компоновкой, а не оборачивай каждый текст:

```js
card.layoutMode = "VERTICAL";
card.itemSpacing = 12;
card.appendChild(titleText);
card.appendChild(bodyText);
```

Проверка:

- отмечай фреймы с ровно одним текстовым узлом и без заливки, обводки, отступов, роли компонента или смысловой задачи компоновки;
- по умолчанию не создавай фреймы-обёртки с одним текстом.
