# Размеры и автоматическая компоновка вайрфрейма

## Правила ширины секций

Каждая секция страницы должна иметь:

- ширину `1280`;
- горизонтальные внутренние отступы `60`;
- внутреннюю ширину содержимого `1160`;
- высоту по содержимому.

Не позволяй внутренним фреймам содержимого или сеткам становиться шире `1160`.

Проверка:

- ни один непосредственный фрейм содержимого секции не шире `1160`;
- ни одна секция не шире `1280`;
- дочерние элементы секции находятся внутри боковых полей по 60 пикселей.

## Контроль ширины при автоматической компоновке

В контейнерах с автоматической компоновкой различай внешнюю ширину и ширину содержимого.

Для каждого дочернего элемента родителя с внутренними отступами:

```js
const contentWidth = parent.width - (parent.paddingLeft || 0) - (parent.paddingRight || 0);
```

Текст, строки, поля, карточки и элементы формы должны ограничиваться шириной содержимого родителя, а не всей шириной его фрейма.

Для текстовых узлов содержимого внутри родителя с автоматической компоновкой:

- задавай `textAutoResize = "HEIGHT"`;
- задавай `layoutSizingHorizontal = "FILL"`, когда текст должен занять доступную ширину содержимого;
- задавай `layoutSizingVertical = "HUG"`;
- не оставляй текст содержимого дочерним элементом фиксированной ширины, если это не короткая подпись, бейдж, чип, подпись иконки, пункт навигации, переключатель языка или подпись кнопки.

Не используй `resize(width, height)` как окончательную модель компоновки текста содержимого. Можно один раз изменить размер для настройки переноса, но итоговое состояние должно по возможности использовать размеры автоматической компоновки.

Проверка:

- текст содержимого в контейнерах с автоматической компоновкой использует `layoutSizingHorizontal === "FILL"`;
- текст содержимого использует `textAutoResize === "HEIGHT"`;
- текст содержимого использует `layoutSizingVertical === "HUG"`, если поддерживается;
- фиксированная ширина текста допустима только для коротких подписей, бейджей, чипов, подписей иконок, пунктов навигации, переключателей языка и подписей кнопок.

## Рекурсивный расчёт ширины содержимого

При вложении контейнеров рассчитывай ширину содержимого на каждом уровне.

Пример:

- ширина секции `1280`;
- внутренние отступы секции `60 + 60`;
- ширина содержимого секции `1160`;
- ширина формы `770`;
- внутренние отступы формы `32 + 32`;
- ширина содержимого формы `706`;
- ширина шага `706`;
- внутренние отступы шага `24 + 24`;
- ширина содержимого шага `658`;
- промежуток между двумя колонками `20`;
- ширина поля `(658 - 20) / 2 = 319`.

Не помещай дочерний элемент шириной `706` внутрь родителя той же ширины с горизонтальными отступами `24px`. Дочерний элемент должен иметь ширину `658` или режим `FILL` внутри области содержимого.

Для колонок внутри родителя с отступами:

```js
const contentWidth = parent.width - (parent.paddingLeft || 0) - (parent.paddingRight || 0);
const columnWidth = Math.floor((contentWidth - gap * (columns - 1)) / columns);
```

Проверка:

- ни один дочерний элемент не шире области содержимого родителя;
- размеры строк, полей, карточек, форм и элементов управления рассчитываются по вложенной ширине содержимого;
- дочерние элементы выравниваются внутри области с отступами, а не по внешнему краю фрейма родителя.

## Только целые значения

Не создавай дробные числовые значения в вайрфреймах Figma.

Применяй только целые значения для:

- `x`, `y`
- `width`, `height`
- внутренних отступов;
- промежутков между элементами;
- промежутков сетки;
- ширины карточек;
- ширины текста;
- размеров шрифта;
- высоты строки;
- радиусов скругления;
- толщины обводки.

Округляй каждое вычисленное значение до вызова `resize`, установки позиций и отступов или применения типографики:

```js
const px = (value) => Math.round(value);

node.x = px(node.x);
node.y = px(node.y);
node.resize(px(width), px(height));
frame.itemSpacing = px(frame.itemSpacing);
frame.paddingLeft = px(frame.paddingLeft);
frame.paddingRight = px(frame.paddingRight);
```

При расчёте сетки распределяй остаток намеренно, чтобы общая ширина оставалась точной, а карточки не получали дробную ширину:

```js
function integerColumns(containerWidth, gap, columns) {
  const totalGap = gap * (columns - 1);
  const base = Math.floor((containerWidth - totalGap) / columns);
  const remainder = containerWidth - totalGap - base * columns;
  return Array.from({ length: columns }, (_, index) => base + (index < remainder ? 1 : 0));
}
```

Проверка:

- ни у одного созданного узла нет дробных `x`, `y`, `width` или `height`;
- промежутки, отступы, зазоры сетки, ширина текста, размер шрифта и высота строки не дробные;
- вычисленный макет не использует значения `.5` как визуальный обходной приём;
- дробные значения образца по возможности сообщаются пользователю, но не попадают в новый вайрфрейм.

## Автоматическая компоновка

Используй значения выравнивания осей Figma Plugin API, а не названия CSS:

- начало → `MIN`;
- конец → `MAX`;
- центр → `CENTER`;
- базовая линия → `BASELINE`;
- не используй `STRETCH` или `FLEX_START` как `counterAxisAlignItems`.

Используй вертикальную автоматическую компоновку фреймов страниц:

```js
frame.layoutMode = "VERTICAL";
frame.primaryAxisSizingMode = "AUTO";
frame.counterAxisSizingMode = "FIXED";
frame.counterAxisAlignItems = "CENTER";
frame.itemSpacing = 0;
frame.resize(1280, frame.height);
```

Используй центрированные контейнеры секций:

```js
section.layoutMode = "VERTICAL";
section.counterAxisAlignItems = "CENTER";
section.primaryAxisSizingMode = "AUTO";
section.counterAxisSizingMode = "FIXED";
section.resize(1280, section.height);
```

Внутри каждой секции создавай фрейм содержимого фиксированной ширины `1280 - 60 * 2 = 1160`, если пользователь не просит другой контейнер. Центрируй его в секции.

## Приведение размеров к норме

Корневые элементы с автоматической компоновкой могут схлопнуться после создания, особенно у больших страниц. После добавления всех дочерних элементов обязательно проверь размеры:

1. Подгони отдельные компоненты.
2. Подгони экземпляры компонентов, если родительскому макету нужны явные размеры.
3. Подгони секции страниц от самых глубоких дочерних элементов вверх, не расширяя контейнеры фиксированной ширины.
4. Последним подгони корневой фрейм страницы, сохранив ширину `1280`.

До подгонки определи контейнеры фиксированной ширины, которые нельзя расширять:

- фрейм страницы: фиксированные `1280`;
- секция: фиксированные `1280`;
- содержимое секции: фиксированные `1160`;
- форма: фиксированная измеренная ширина, например `770`;
- блоки шагов и содержимого: заполняют область содержимого родителя, не расширяя его;
- контейнеры сетки и карточки: фиксированная ширина по вычисленной ширине колонки или содержимого.

Используй подобную вспомогательную функцию и подстрой размеры к реальному макету:

```js
function isFixedWidthContainer(node) {
  return /Page|Section|Content|Form|Step|Grid|Card/i.test(node.name || "");
}

function fitGeneratedWireframe(node) {
  if (!("children" in node)) return;
  for (const child of node.children) fitGeneratedWireframe(child);

  if (node.layoutMode === "VERTICAL") {
    const children = node.children || [];
    const spacing = node.itemSpacing || 0;
    const paddingY = (node.paddingTop || 0) + (node.paddingBottom || 0);
    const height =
      children.reduce((sum, child) => sum + child.height, 0) +
      Math.max(0, children.length - 1) * spacing +
      paddingY;
    if (height > 1 && "resize" in node) node.resize(node.width, height);
  }

  if (node.layoutMode === "HORIZONTAL") {
    const children = node.children || [];
    const spacing = node.itemSpacing || 0;
    const paddingX = (node.paddingLeft || 0) + (node.paddingRight || 0);
    const width =
      children.reduce((sum, child) => sum + child.width, 0) +
      Math.max(0, children.length - 1) * spacing +
      paddingX;
    const height = Math.max(
      node.height,
      ...children.map((child) => child.height + (node.paddingTop || 0) + (node.paddingBottom || 0)),
    );
    if (height > 1 && "resize" in node) {
      node.resize(isFixedWidthContainer(node) ? node.width : width, height);
    }
  }
}
```

Не запускай общую подгонку, расширяющую фиксированные контейнеры вверх по дереву. Если дочерние элементы переполняют родителя, исправь их размеры или вложенный расчёт ширины содержимого вместо расширения родителя.

Выполни это перед итоговой проверкой качества:

```js
for (const component of [headerComponent, footerComponent, buttonComponent]) {
  fitGeneratedWireframe(component);
}
for (const pageFrame of generatedPageFrames) {
  fitGeneratedWireframe(pageFrame);
  pageFrame.resize(1280, pageFrame.height);
}
```
